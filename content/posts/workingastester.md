# My Experience as a Tester

Working as a **Tester at Endava Vietnam** was an incredibly rewarding journey — a time when I grew both technically and professionally. I got hands-on experience with testing fundamentals, automation, team communication, and building real tools that helped deliver quality products.

---

## 🤝 Teamwork & Communication

Throughout my time in the team:

* I learned how to **listen actively and communicate clearly** with developers, Product Owners (POs), and fellow testers.
* Daily collaboration helped me understand requirements, clarify expected behaviors, and share feedback effectively.
* Communicating bugs and validating fixes improved the **quality of each sprint outcome**, making team goals more achievable.

These skills taught me that **testing is a team sport** — a collaboration where clear communication is just as important as technical skill.

---

## 📚 Testing Foundations

Learning foundational testing principles helped me structure my work:

* I studied **ISTQB testing concepts** and applied them in real scenarios.
* I practiced **test analysis and test design**, which guided me in writing meaningful and targeted test cases.
* I used **Jira to manage tasks**, track progress, and report defects with clarity.

---

## 🧪 API Testing & Tools

One of my core areas of focus was API testing:

* I used **Postman** to perform API testing — building collections, writing test scripts, and organizing tests for repeatable execution.
* Postman helped me validate endpoints quickly and ensure consistent behavior across environments.

## 🔁 CI/CD: Automating Regression Testing

To ensure our tests ran consistently after each release:

* I configured **Git version control**, pushing all framework updates to **GitLab**.
* I set up a **Jenkins freestyle job** that:
  * pulled changes from the repository,
  * executed the full test suite after each release,
  * generated test logs and reporting artifacts.

This brought **automation into our release process**, reducing manual effort and catching regressions earlier.
